# Переводчик игр

Android-приложение переводит текст прямо поверх игры: снимает экран, распознаёт надписи и отправляет новые строки в Gemini.

Подписи рисуются там, где был исходный текст, и не перехватывают касания. Повтор одной и той же реплики берётся из памяти на телефоне, поэтому в сеть уходит только новый текст.

## Как пользоваться

1. Соберите и установите приложение в Android Studio (или `./gradlew :app:assembleDebug`).
2. Вставьте ключ Gemini из [Google AI Studio](https://aistudio.google.com/apikey). Ключ остаётся в памяти приложения на телефоне и в репозиторий не входит.
3. Выберите язык текста в игре (латиница, японский, китайский или корейский) и язык перевода.
4. Нажмите «Проверить ключ».
5. Разрешите показ поверх других окон и захват экрана.
6. Откройте игру. Плавающая панель сверху справа ставит перевод на паузу или останавливает его. Её можно перетащить.

Для диалогов и субтитров нажмите «Выбрать область» и обведите только эту часть экрана. Так распознавание быстрее и меньше путает интерфейс.

По умолчанию экран смотрится каждые 0,7 с. Новая фраза уходит в модель `gemini-3.5-flash-lite` после двух одинаковых кадров, чтобы дрожание распознавания не плодило запросы. Ответ обычно приходит примерно за секунду. Уже виденный текст показывается сразу.

Модель «Точнее (Flash)» — `gemini-3.5-flash`. У неё отключены внутренние рассуждения, чтобы ответ не задерживался.

## Сборка

Нужны JDK 17 и Android SDK 35.

```bash
export ANDROID_HOME="$HOME/android-sdk"
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

Готовый пакет: `app/build/outputs/apk/debug/app-debug.apk`.

## Ограничения

- Игра с запретом снимка экрана даёт чёрный кадр. Обойти это приложение не пытается.
- Рукописные и сильно стилизованные шрифты распознаются хуже обычного интерфейса.
- Перевод идёт через интернет. Без сети остаются только уже запомненные строки.
